## Featured Projects

### EasyPDF — Full-Stack PDF Processing Platform
*A scalable web service offering 13+ secure PDF manipulation operations.*
- **Backend Architecture**: Built with **FastAPI** to handle concurrent document processing.
- **Core Engine**: Integrated PyMuPDF, pypdf, and Pillow for high-fidelity cross-platform conversions (e.g., DOCX-to-PDF).
- **Security & Scale**: Implemented Google OAuth authentication and an SQLite-based rate-limiting system to ensure service stability.
- **Deployment**: Fully containerized for web deployment.
- **Links**: [Repository](#) | [Live Demo](#)

### Cloud Smart Log Analyzer
*An automated, event-driven log parsing pipeline built on serverless infrastructure.*
- **Cloud Architecture**: Orchestrated **AWS Lambda** workflows triggered asynchronously via **S3** bucket events.
- **Data Pipeline**: Parsed and structured raw logs into **DynamoDB** for rapid querying.
- **Observability**: Integrated SNS for real-time alerting and CloudWatch for system monitoring.
- **Links**: [Repository](#)

### Cryptographic Hardware Accelerator
*Cycle-accurate hardware implementation of advanced mathematical transformations.*
- **Hardware Design**: Designed an RTL implementation in **Verilog** for accelerating modular arithmetic.
- **Algorithm**: Focused on Number Theoretic Transform (NTT), targeting post-quantum cryptography concepts.
- **Verification**: Conducted rigorous functional validation using **ModelSim**.
- **Links**: [Repository](#)

### NLP-Based Product Review Analyzer
*A machine learning pipeline for granular sentiment extraction from e-commerce text.*
- **Data Engineering**: Processed and normalized a dataset of 15K+ Amazon reviews.
- **Model Pipeline**: Implemented TF-IDF combined with Support Vector Machines (SVM) for baseline classification.
- **Advanced NLP**: Leveraged **DistilBERT** to perform feature-level sentiment extraction, mapping context to specific product attributes.
- **Links**: [Repository](#)
